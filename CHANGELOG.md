# Changelog

All notable changes to the Agent Governance Scorecard.

## [v1.1-draft] — 2026-09-04

### Added
- **SC-4.4** Effective authority bounded per task — agent authority scoped to the task, not inherited from the operating credential
- **SC-4.5** Delegation-boundary enforcement — governance controls apply to sub-agents; identity-scoped prohibitions cannot be circumvented by spawning a new identity
- **SC-5.4** Earned autonomy — autonomy expands on demonstrated conformance and contracts on decline (symmetric with Agent Baseline AUT-10)
- **Theoretical Basis** section — GFT fidelity-chain derivation of the six dimensions and non-compensable scoring model
- **GOVERNANCE.md** — disposition process for public comment
- **DISPOSITIONS.md** — disposition log with two pre-window deferred items (peer-influence, evidence-format portability)
- **CHANGELOG.md** — this file
- Issue templates for proposed-change, gap-report, and evidence-challenge

### Changed
- Criteria numbered as **SC-x.y** for stable public-comment references
- Scoring thresholds adjusted for 25 criteria (from 22)
- Non-compensable scoring model made explicit in scoring section
- Rubric language tightened where v1.0 assessments surfaced ambiguity (SC-2.1 clarifies "captured externally at decision time, not reconstructed post-hoc"; SC-6.4 clarifies "not just performance metrics")
