## About

Six dimensions, 20 criteria for evaluating agent governance. The scorecard provides objective criteria for evaluating any AI agent platform's governance readiness.

The document in this repository (`SCORECARD.md`) is the v1.0 text as served on 2026-08-19.

## Status

v1.0 is the **stable normative basis**. The living, iterating line is the [Raknor Operationalized Agent Governance Scorecard](https://raknor.ai/standard.html), which carries the standard forward with adversarial testing scenarios and operationalized criteria.

## Issues

Errata, clarifications, questions, and v1.1 proposals are welcome here. This repository is the venue for changes to the Agent Governance Scorecard. Changes to the Raknor operationalized standard have a [separate proposal process](https://github.com/raknor-ai/agent-governance-standard/issues/1).

Errata may produce v1.0.x patch releases — normative content is frozen, typos are fixable.
